# Overview
The plan is to start by working mostly with 3D printing as the infrastructure is often the best documented, and more consistant to navigate, then other platforms will be added as resources to do so become available. The goal is to make administration of makerspaces and fabrication easier to foster greater community investment in local machine aided manufacturing.
