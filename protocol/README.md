# Open Fabrication (OpenFAB)

OpenFab is a project aimed at streamlining digital fabrication infrastructure including:
1. 3D printing.
2. Laser Cutting.
3. Commerical Embroidery.
4. NCC (Numerical Computer Control) Routing and Milling.
5. Photo Printing.
6. Screen and Fabric Printing.
7. Circuit Board Manufacturing.
8. Water jet cutting.

Any many others.
